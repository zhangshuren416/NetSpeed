# 网速悬浮窗 (NetSpeed Monitor)

Windows 桌面悬浮窗，实时显示当前网络的 **下载 / 上传速度**，支持**逐网卡详情**与**多粒度流量统计**。纯 Python 标准库实现，无任何第三方依赖；已打包为独立 exe，双击即用。

## 快速开始

| 方式 | 操作 |
| --- | --- |
| **独立 exe（推荐）** | 双击 `dist\NetSpeed.exe`，无需安装 Python |
| 脚本运行 | 双击 `启动网速悬浮窗.bat`（需要已安装 Python 3） |
| 命令行 | `pythonw.exe netspeed.pyw` |

启动后，悬浮窗出现在**屏幕右上角**，按设定间隔刷新：

```
↑   1.2 MB/s   ← 上传速度（蓝色）
↓  12.3 MB/s   ← 下载速度（绿色）
```

## 操作说明

- **拖动**：按住悬浮窗任意位置拖动，位置自动记忆，下次启动恢复。
- **靠边自动隐藏**：把悬浮窗拖到屏幕任一边缘附近（约 20 像素内）松手，会自动贴边吸附；鼠标移开后窗口滑出屏幕、只留一条细边，鼠标放到细边上又自动展开，移开后再次隐藏。按住细边可直接拖走，拖离边缘即恢复正常模式。右键菜单「靠边自动隐藏」可开关（默认开启）。
  - 细边带**浅色边框**，深色桌面/浅色壁纸下都清晰可见；
  - 细边内以**速度条**显示实时网速：左右停靠时上半上传（蓝）、下半下载（绿）；上下停靠时左半上传（蓝）、右半下载（绿）。条长随速度变化（对数刻度，1 GB/s 满格，有流量即有显示），随刷新间隔同步更新。
- **双击悬浮窗**（或右键 →「网卡详情与流量统计」）：打开详情窗口。
- **右键菜单**：
  - 网卡详情与流量统计
  - 刷新间隔：0.5 / 1 / 2 秒
  - 透明度：100% / 92% / 80% / 60%
  - 靠边自动隐藏：开 / 关
  - 数据保留：7 / 30 / 90 / 365 天（默认 30 天）
  - 开机自启：写入当前用户的注册表 Run 项，可随时取消
  - 重置位置 / 退出
- 单实例运行：重复启动会自动退出，不会开出多个窗口。
- 窗口置顶、不在任务栏和 Alt-Tab 中显示；Win11 下自动圆角，高 DPI 屏幕清晰显示。

## 网卡详情与流量统计

详情窗口与悬浮窗统一的深色主题：自定义标题栏（可拖动，✕ 或 Esc 关闭）、卡片式网卡行（下载绿 / 上传蓝、等宽数字右对齐）、分段式粒度切换、总量大数字卡片、每张网卡的流量占比条，内容多时可滚轮滚动。分两部分：

1. **实时速度**：每张已连接网卡的名称、下载速度、上传速度，随悬浮窗同步刷新。
2. **流量统计**：按粒度查看每张网卡及合计的下载 / 上传 / 总流量：
   - 本次运行 / 最近1小时 / 最近12小时 / 最近1天 / 最近7天 / 全部
   - 数据按**分钟粒度**存入 SQLite，**重启程序不丢失**。保留期右键菜单「数据保留」可选 **7 / 30 / 90 / 365 天**（默认 30 天），启动时与运行期每小时自动清理过期数据，切换后立即生效。
   - 占用极小：每分钟每网卡约 43 字节，单网卡每天约 62 KB——30 天约 2 MB、365 天也仅约 22 MB（多网卡按倍数计）。

> 统计口径说明：速度来自 Windows 网卡 64 位字节计数器的差分，是真实流量而非估算。
> 流量统计只能累计**程序运行期间**的数据（关闭期间无法采样）；想要接近全天候的统计，
> 请在右键菜单开启「开机自启」。多张网卡同时联网时，悬浮窗显示所有已连接网卡的合计速度。

## 统计口径（技术细节）

- 通过 Windows IP Helper API（`GetIfTable2`）读取网卡 64 位字节计数器，两次采样差分得到实时速度，**不产生额外网络请求**。
- 用 `GetAdaptersAddresses` 过滤出真实网卡：只统计**已连接**的网卡，排除回环、隧道接口，以及 WFP/QoS 等过滤驱动行（它们镜像主网卡计数，直接求和会重复计数）。
- 单位按 1024 进制自动切换：B/s → KB/s → MB/s → GB/s。

## 数据与配置文件

| 文件 | 说明 |
| --- | --- |
| `%APPDATA%\NetSpeedMonitor\config.json` | 位置、刷新间隔、透明度、默认统计粒度、靠边自动隐藏开关、数据保留期 |
| `%APPDATA%\NetSpeedMonitor\traffic.db` | SQLite 流量历史（分钟 × 网卡） |

删除 config.json 恢复默认设置；删除 traffic.db 清空流量历史。
开机自启状态保存在注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `NetSpeedMonitor` 值中。

## 常见问题

- **SmartScreen 提示"已保护你的电脑"**：exe 未购买数字签名，属正常现象。点"更多信息 → 仍要运行"即可；介意的话可直接用脚本方式运行（源码完全透明）。
- **速度显示为 0**：确认当前有程序在传输数据；悬浮窗统计的是整机所有已连接网卡的流量。
- **统计里只有最近几分钟的数据**：统计从程序本次启动开始累计；开启开机自启后可长期积累。
- **窗口跑到屏幕外**（换显示器后）：右键菜单 → 重置位置；或删除配置文件。

## 技术栈选型

**Python 3 标准库（tkinter + ctypes + sqlite3）+ PyInstaller 打包**，理由：

1. **零依赖、可审计**：悬浮窗 + 计数器读取 + 本地数据库全部用标准库完成，单文件源码约 700 行，无第三方运行时、无网络组件，安全透明。
2. **数据源权威且零开销**：ctypes 直接调用 `iphlpapi.dll`（任务管理器同源的系统计数器），每次采样仅一次系统调用 + 一次内存拷贝，CPU 占用可忽略，无需管理员权限。
3. **环境契合**：本机已有 Python 3.12（含 tkinter），没有 .NET SDK / Go / Rust 工具链；C# WPF 需要额外运行时，Electron 为一个小组件引入 100MB+ 的 Chromium 得不偿失，Qt 有第三方依赖与授权问题。
4. **分发简单**：PyInstaller 打成单文件 exe（约 12MB），双击即用；tkinter 的朴素外观对"小工具"足够，详情表格用 ttk 原生控件呈现。

权衡：tkinter 的 UI 表现力不如 WPF/Qt（无亚克力/动画等现代效果），换来的是零依赖、体积小、源码完全可读。
